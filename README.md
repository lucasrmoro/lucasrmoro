## 🚀 Featured Projects

### [ComposeSample](https://github.com/lucasrmoro/ComposeSample)

An Android architecture reference built with Kotlin, Jetpack Compose, and MVI. It explores how features and shared services can evolve independently through explicit contracts.

Key architectural choices:

- Feature modules with separate presentation, domain contracts, domain implementations, data, and dependency bindings.
- Shared services organized into API, implementation, and DI modules.
- A dependency injection abstraction backed by Koin, keeping framework details behind contracts.
- Unidirectional UI flow with events, state, and one-off effects.
- Navigation between features through shared destination contracts and registered entry points.
- Centralized application startup and reusable Gradle convention plugins.

The project includes infrastructure for networking, storage, analytics, notifications, permissions, biometrics, and media.

**Status:** In development, with illustrative business logic and placeholder backend endpoints.
